## 🚀 Caractéristiques principales

* **Portée mondiale :** Prise en charge complète des numéros de téléphone de tous les pays.
* **Haute précision :** Logique de validation avancée pour garantir des résultats précis.
* **Intégration de proxys :** Prise en charge intégrée de plusieurs types de proxys (formats ip:port ou ip:port:utilisateur:mot_de_passe) pour garantir une vérification optimale.
* **Multitraitement :** Tire parti du traitement multicœur pour une validation simultanée ultra-rapide.
* **Utilisation illimitée :** Aucune restriction quant au nombre de numéros que vous pouvez valider.

## 📘 Cas d'utilisation

* **Nettoyage des données :** Supprimez les entrées invalides de vos listes marketing.
